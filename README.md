# CODE_CULTURE_PORTAL

![Portal Preview](preview.gif) *Example visualization - replace with actual screenshot*

An interactive web experience where creative coding meets cultural resistance. This portal blends p5.js visualizations with radical digital aesthetics to create a living ecosystem of resistance, reflection, and realignment.

## ✨ Features

### Three Interactive Dimensions
- **Resistance**: Particle systems that push against user interaction
- **Reflection**: Distorted media mirrors with adjustable bias sliders
- **Realignment**: Audio-reactive visualizations for collective tuning

### Technical Highlights
- Dynamic p5.js canvases for each section
- Web Audio API integration for microphone input
- Responsive design with striking color palette
- Glitch aesthetics and digital distortion effects

## 🛠️ Installation
1. Clone repository:
```bash
git clone https://github.com/your-username/code-culture-portal.git
```
2. Install live server (if needed):
```bash
npm install -g live-server
```
3. Run project:
```bash
live-server
```

## 🌐 Deployment
The portal is designed for static hosting. Deploy to:
- GitHub Pages
- Netlify
- Vercel
- Any static file host
